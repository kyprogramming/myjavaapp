📖 About the Project

This is a Spring Boot web application that demonstrates how to build modern web apps with Java. It uses MVC architecture, Thymeleaf templates, PostgreSQL database, and responsive design — all running in a single Docker container.

Technologies Used

☕

Java 17

Modern Java features power the backend logic.

🌱

Spring Boot

Web framework that manages everything behind the scenes.

🍃

Thymeleaf

HTML templates that render dynamic data seamlessly.

🐘

PostgreSQL

Powerful open-source relational database for persistent data storage.

🐳

Docker

Containerized deployment with PostgreSQL and app in a single image.

🔗

Spring Data JPA

Simplifies database operations with Hibernate ORM under the hood.
